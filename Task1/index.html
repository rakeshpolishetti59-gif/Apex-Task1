Foundational Web Technologies

Explore the three core technologies that power every webpage on the internet.

Structure

Create a Simple Webpage Using HTML

HTML (HyperText Markup Language) builds the skeleton of every website. It organizes content into meaningful building blocks.

  • Headings: Tags from <h1> to <h6> define page hierarchy and section titles.
  • Paragraphs: The <p> element groups body text, articles, and explanations cleanly.
  • Images: The <img> tag embeds visual media using the src and alt attributes.
  • Links: The <a> anchor tag creates hyperlinks to connect other pages using href.
💡 Tip: HTML tags describe what content is, not how it looks.
Styling

Style the Webpage Using CSS

CSS (Cascading Style Sheets) brings visual life, elegance, and structure to raw HTML elements across all devices.

  • Colors: Defines text, background, and border hues with HEX, RGB, or HSL color palettes.
  • Fonts: Customizes font family, size, weights, and line-heights for optimal readability.
  • Spacing: Controls padding (inner space) and margins (outer space) around page elements.
  • Layout: Organizes responsive grids and flex containers that adapt to any screen size.
🎨 Tip: CSS separates presentation from structure for easier maintenance.
Interactivity

Add Basic JavaScript for Interactivity

JavaScript adds intelligence and dynamic behavior. It listens to user actions, updates content, and handles events in real time.

  • Event Listeners: Detects user inputs like clicks, hover states, and keyboard presses.
  • DOM Manipulation: Modifies HTML elements and styles on the fly without refreshing the page.
  • Interactive Alerts: Communicates immediate feedback, confirmations, and alerts to users.
